项目 / 变量数学定义与计算规则
五年合并与插补合并 2021–2025 秋季学期；UC 原始表中 <3 人留空，若 App 非空而 Adm 留空（或 Adm 非空而 Enr 留空），按 1 人插补。
经验贝叶斯先验 (亚裔口径)logit(r₀) = a₀ + a₁·logit(r_all)，收缩后比例 r̂ = (a_adm + K·r₀) / (a_app + K)，其中 K_rate = K_yield = 50。
标准化特征 z₁, z₂x₁ = ln(r/(1−r)), x₂ = ln(y/(1−y))；z₁ = (x₁ − μ₁)/σ₁, z₂ = (x₂ − μ₂)/σ₂（全体按全州 1,460 校标准化；亚裔按 a_app ≥ 60 池标准化）。
岭回归目标与求解y_i = logit(actual_i + 0.005)，最小化 ‖X b − y‖² + λ(b₁² + b₂²)（λ = 3.0）；预测 p̂ = 1 / (1 + exp(−(b₀ + b₁z₁ + b₂z₂)))。
加州全州 UC 原始分r̂, ŷ 先向全州均值做 Beta(K=50) 收缩，再算 S = z_r − clip(z_r, 0, 1)·z_y；90% 名次区间由 2,000 次 Beta 后验抽样得出。
