用数据回答两个家长最关心的问题

这个网站整理了我们在本仓库里做的两项独立研究。两项研究的数据来源、方法和结论都不一样，所以分开呈现； 每一页都会先讲清楚数据从哪来、怎么算的、能信到什么程度，再给出结果。

研究一

湾区高中研究

问题：湾区哪些公立高中的毕业生，更多去了“比伯克利更难进/更受青睐”的大学？

  • 数据：UC 官方按高中公布的申请/录取/入学人数（2021–2025）
  • 校准：27 所学校公布的真实升学名单
  • 结果：湾区公立高中 Top 50（全体口径 + 亚裔口径）

研究二

大学排名研究

问题：同时被两所大学录取的学生，最后“用脚投票”选了哪一所？

  • 数据：Parchment 公开的“交叉录取”对决数据（3,350 组）
  • 方法：Bradley-Terry 模型（类似国际象棋 Elo 等级分）
  • 结果：97 所美国大学 / 文理学院的“学生偏好”排名

两项研究怎么连在一起？

它们是独立的，但有一个交汇点：高中研究里“好大学”的标准，直接借用了大学研究的结果。

大学排名研究根据交叉录取数据给每所大学打分
→
定义“顶尖去向”得分高于 UC 伯克利、且不属于 UC 系统的 6 所大学：MIT、Stanford、Yale、Harvard、Princeton、Columbia
→
湾区高中研究预测每所高中毕业生中去这些学校的比例

使用前请注意

  • 这是研究原型，数字带有误差；排名相邻的学校通常没有实质差别，请看区间而不是名次。
  • 所有数据均来自公开来源（UC Information Center、学校官网、Parchment），我们没有任何学生个人数据。
  • “去了更好的大学”只是一个可量化的视角，不代表学校教育质量的全部。
