05模型方程与四模型设定对照表

Wilson 区间样本量反推、高斯核加权极大似然与交叉验证超参数

数学方程与估计方法

步骤数学公式与数值实现
1. Wilson 区间反推 (k, n)已知公布胜率 p₀ (整数%) 与 95% 区间 [L₀, U₀] (z=1.95996)，在 n ∈ [1, 10000] 内枚举 k = round(p₀·n)，计算 Wilson 上下界 (L(k,n), U(k,n))，取误差 |L−L₀| + |U−U₀| + 0.5|k/n−p₀| 最小者 (例如 Harvard vs Yale: 62% [57.3%–66.5%] → n=424)。
2. Bradley-Terry 概率P(i ≻ j) = σ(θ_i − θ_j) = 1 / (1 + exp(−(θ_i − θ_j)))，满足约束 ∑_i θ_i = 0。分差 Δθ = 0.5, 1.0, 2.0 对应胜率 62.2%, 73.1%, 88.1%。
3. 高斯核分档加权似然L(θ) = ∑_{(i,j)} w_{ij} [k_{ij} ln P(i ≻ j) + (n_{ij} − k_{ij}) ln(1 − P(i ≻ j))] − (λ/2) ∑_i θ_i²，其中核权重 w_{ij} = exp(−(θ_i − θ_j)² / 2h²) 随外层迭代更新至 max|Δθ| < 10⁻⁶。
4. 协方差与自举名次区间收敛后取负 Hessian 逆矩阵 Σ = (−H)⁻¹，标准误 SE_i = √Σ_{ii}；从多元正态分布 N(θ, Σ) 抽取 2,000 组样本并排序，取 2.5% 与 97.5% 分位数作为 95% 名次区间 [rank_lo, rank_hi]。
